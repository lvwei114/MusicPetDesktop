# MusicPet · 音乐桌宠 v0.3

原生 Windows 音乐桌宠，支持静态图片，以及音乐播放时的 GIF / APNG / MP4 动态皮肤。双击 **MusicPet.exe** 或 **启动桌宠.cmd** 使用。

## 2026-10-28 更新

新增内置 **mika** 组合预设。在「桌宠形象」中选择 mika，音乐播放时显示 APNG 动画，暂停后完成当前循环并恢复静态图。默认 1 倍速，关闭往返；支持自行调整并保存。默认启动形象仍为大肥鱼。

组合文件为 `skins/mika.pet.ini`，素材在 `skins/mika/`，移动时请保留整个 skins 目录。素材由用户提供，其授权独立于源码 MIT 许可。

## 动画速度与往返播放

### 静态／动态画布对齐修复

有动态素材的组合使用静态原始画布作为固定显示区域，静态图不再单独裁透明边距。静态与动态共用完整画布等比缩放、同一采样器、水平居中及底部对齐；动画不按帧裁边。相同画布且角色位置相同的素材，切换时尺寸和位置一致。不同画布比例会保留透明留白，不能自动修正素材本身的角色比例或构图差异。纯静态预设仍保留原裁透明边距行为。

最新版分发包中的 `MusicPet.exe` 已包含此修复，尚未签名。`qa/artwork-alignment-report.txt` 验证 64/131/300/525 像素下静态共用绘制与 APNG 的逐像素 alpha 一致，以及正放、往返、固定锚点和动画回归。

「桌宠形象 → 动画速度」支持 0.25、0.5、0.75、1、1.25、1.5、2 倍速；「往返播放」可单独勾选。GIF、APNG 和 MP4 均支持。选定组合时，两项设置直接保存到该组合的 `.pet.ini`，切换或重启后恢复；没有组合的旧版全局动画则保存到 MusicPet.ini。旧预设默认 1 倍速、关闭往返。

往返序列为 1→2→3→4→3→2→1…，端点不重复停留；暂停后播完当前往返轮次再切回静态图。更改速度或往返设置会从头播放。慢放及往返会延长暂停后的收尾时间。

往返使用合成、缩放后的完整画面缓存，避免局部动画帧倒序造成残影；缓存最多 128 MB、4096 帧。超限回退静态图并提示，可调小桌宠尺寸、缩短素材或关闭往返。普通正放仍使用原有流式解码。

本次验证记录：`qa/motion-playback-options-report.txt`、`qa/pair-playback-options-report.txt`、`qa/playback-options-ui-report.json`。界面测试副本仅更换窗口/互斥锁命名空间及托盘 GUID，以避开正在运行的旧实例。

最新版已打包为 **MusicPet-2026.10.28-win-x64.zip**。请从 [Releases](https://github.com/lvwei114/MusicPetDesktop/releases/latest) 下载并完整解压，退出旧桌宠后运行 `MusicPet.exe`。本包未签名，Windows SmartScreen 可能提示。

## 2026-10-26 更新

- 「桌宠形象 → 添加动态素材并保存组合预设」：将当前静态图与 GIF、APNG 或 MP4 成对保存，可为组合命名。同一静态图可以有多个不同动画组合。「另存当前静态＋动态组合」可保存新组合并改名。菜单中的 `[组合]` 标记用于区分组合与普通静态预设。
- 选择组合会同时切换静态图和动态素材；选择普通静态预设会清除当前动画，已保存组合仍保留。「关闭动态皮肤」只影响当前选择，不删除已保存组合。
- 组合保存在 `skins/*.pet.ini`，名称和素材相对路径都记录在该文件中，素材复制在程序的 skins 目录。搬移时保留完整 skins 目录；已选组合通过文件名恢复，不依赖原安装路径。旧版全局 Motion 配置仍可读取，重新添加动态素材即可保存为组合。
- APNG 支持 `.apng` 及实际含动画的 `.png`；支持透明、部分帧区域、SOURCE/OVER 叠加、背景/前帧恢复与帧延时。限制 400 万画布像素、4096 帧、256 MB 文件，损坏数据或不兼容内容回退静态图；普通 PNG 应作为静态图导入。WebM 本轮暂不支持。
- 音乐暂停或停止后，GIF/APNG/MP4 继续播放当前一轮的剩余部分，包含末帧显示时间，然后切回静态图；期间恢复音乐会取消停止请求并继续循环。轮次已经结束后再恢复，则从头播放。切换预设、关闭动态皮肤和退出程序会立即中止旧动画。长视频的剩余部分也会完整播放。
- 新导入的动态素材上限统一为 256 MB。解码仍在后台执行，只保留最新输出帧；不需要第三方解码运行库。

验证：`qa/motion-20261026-report.txt`（APNG 独立像素参考、GIF/MP4/APNG 收尾停止、恢复、坏文件），`qa/pair-20261026-report.txt`（组合保存、命名、去重、路径边界），`qa/pair-ui-20261026-report.json` 与 `qa/pair-relocation-20261026-report.json`（选择、恢复、搬移后启动）。所有本轮测试副本及输出均保存在项目 qa 内。本包未签名。

## 2026-10-24 更新（历史记录，动态皮肤行为以本次更新为准）

- 新安装默认图片为 `skins/大肥鱼.png`，默认预设不含 Ellie。旧用户的静态皮肤选择保留；工作区旧 Ellie 移至 `skins/legacy/`，不进入新分发包。该目录不出现在顶层预设扫描中。
- 「桌宠形象 → 选择播放时的 GIF / 视频」：选定本地 GIF 或 MP4 后复制至 `skins/motion/` 并保存路径。音乐播放时静音循环，暂停或停止后切回当前静态图，恢复播放后动画从头开始。静态图和动态素材分开配置；动态画面等比放入静态桌宠区域。
- GIF 使用 WIC，支持帧延时、透明和帧恢复处理。逻辑画布最多 400 万像素、4096 帧。视频使用系统 Media Foundation，优先 MP4/H.264，最多约 830 万像素；普通 MP4 没有透明背景。选择文件上限 1 GB，具体兼容性取决于本机解码器；损坏或不兼容素材回退静态图。解码在后台执行，仅保存最新输出帧，无需 FFmpeg 运行库。
- 「播放器 → 音乐播放模式」：随机开关、不循环、单曲循环、列表循环。读取实际系统状态并发送 GSMTC 请求；播放器未开放的能力禁用，不模拟鼠标，不保证所有播放器支持。
- 「桌宠形象 → 调整桌宠大小」：独立原生滑动条，100～600 逻辑像素高度，100 ms 节流预览；确定保存、取消恢复、默认大小 300。音符布局随尺寸调整。
- 字幕气泡本轮暂缓。

本轮测试：`qa/motion-report.txt`（GIF / MP4 循环、暂停恢复、尺寸改变、无效文件）；`qa/media-20261024-report.txt`（随机与循环控制及媒体链路）；`qa/size-ui-report.json`（滑动条）；`qa/smoke-20261024-report.json`（窗口交互）。播放器模式为本地真实 SMTC 模拟会话验证，不等于所有音乐客户端均支持。

## 操作

- 拖动角色：移动位置。松开后保存；重启仍在原位。
- 右键角色：打开控制面板。也可以点击或右键托盘里的绿色音符。
- 面板上方选择播放器；播放、暂停、上一首、下一首会发给当前选定会话。
- 「桌宠形象」：选择 PNG / JPG / BMP 后自动将原文件复制到 skins 保存为预设；相同文件内容复用已有预设，同名不同图追加编号。可切换预设、调整大小，原图移动后仍可使用副本。复制失败时提示，本次仍使用原路径。
- 「音符效果」：随系统报告的播放状态出现；暂停后自然消散。
- 「更多设置 → 音符配色」：默认配色 / 跟随图片，自动保存；换图后重新取色，新生成音符应用新配色。透明或灰度图片无可用彩色样本时回退默认。音符包含四分、八分、双八分、十六分音符及少量星光。
- 「更多设置 → 音符预览」：不播放音乐也能预览 8 秒。
- 「点击穿透」：让角色不拦截鼠标。首选快捷键默认为 **Ctrl + Alt + P**；更多设置中可选择四种组合或关闭。冲突时自动尝试备用组合，菜单显示实际生效的快捷键。再次启动 MusicPet.exe 或运行 恢复桌宠.cmd 会关闭穿透并打开面板。
- 「更多设置 → 配置启动软件」：手动选择 EXE / LNK，或自动查找常见音乐客户端；自动查找后选择一个结果保存。点击「打开指定软件」启动，路径失效时重新配置。查找范围包括运行进程、安装注册表、开始菜单及常见目录，不扫描全盘。
- 「更多设置 → 找回桌宠」：关闭穿透并把角色放回屏幕右下方。
- Esc 或点击面板外部关闭面板。面板也支持 Tab、Enter / 空格。

## 播放器与游戏

读取 Windows GSMTC 系统媒体会话，不采集音频，不录音，不访问音乐账号。
播放器必须提供系统媒体会话；没有接入的客户端不能仅靠此接口获取状态。
网易云、酷狗等客户端可能需要在其设置中开启 SMTC / 系统播放控件。
客户端可能不提供进度或某个控制按钮，此时显示未知进度或禁用对应按钮。
手动选定会话消失后，只有同一来源应用恰好存在一个会话时才自动重新关联；多个候选时等待手动选择，避免控制错误的标签页。
播放器提供有效时间轴时，播放进度按系统时间戳及播放速率推算，暂停后停止，新的时间轴数据用于校正；没有有效时间轴时仍显示未知进度。

支持普通窗口和经实际验证的无边框全屏场景；未做游戏内注入，不能保证覆盖独占全屏或受保护游戏。
游戏模式开启穿透并降低音符数量和刷新率。游戏兼容性需逐游戏测试。

## 文件

- `MusicPet.exe`：64 位独立程序，静态链接 C++ 运行库，无需安装 .NET / Electron。
- `skins/大肥鱼.png`：用户提供的新默认静态图，原图未改动；可替换，再分发需确认图片授权。
- `MusicPet.ini`：首次保存设置后生成，和程序放在一起。删除它会恢复默认设置。
- `src/`：重写后的源码。
- `qa/preview-dark.png`、`qa/preview-light.png`：同一套绘制代码导出的外观预览，曲目信息为演示数据。
- `qa/actual-panel.png`：本机 175% 缩放下的实际控制面板截图。
- `qa/smoke-report.json`、`qa/media-report.txt`：交互与系统媒体链路验证结果。
- `legacy-before-rewrite.zip`：重写前的代码、构建脚本和旧程序备份。

## 构建

要求 Windows 10 1809+ / Windows 11，MSVC C++ Build Tools、Windows SDK（含 C++/WinRT）。
运行 `pwsh -File .\build.ps1`，生成 `MusicPet.exe`。当前在 Windows 11 x64 构建验证。

## 验证入口

- `MusicPet.exe --preview --panel`：打开桌宠并预览音符和面板。
- `MusicPet.exe --render-preview`：不创建桌面窗口，导出 qa 下的深浅背景预览。
- `MusicPet.exe --preview --panel --quit-after=14000`：临时窗口检查，14 秒后退出，不保存设置。
- `qa/smoke.py`：需要 Python + Pillow，测试窗口样式、穿透恢复、特效停止、关闭和重新打开面板、正常退出。
- `qa/media-integration.cpp`：本地发布 SMTC 测试会话，真实调用系统接口验证读取、时间轴、播放/暂停/切歌及指定会话消失后的行为。

未逐一安装测试各音乐客户端；模拟会话通过不等于所有客户端都提供全部字段。

## 自定义皮肤名称

成功选择并保存图片后会出现命名窗口；取消时保留已有名称或文件名。也可在“桌宠形象 → 自定义当前皮肤名称”中随时修改。名称写入 SkinNames.ini，菜单显示自定义名称，原图文件名不变。
